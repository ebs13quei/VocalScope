# VocalScope (ボーカル音域プロファイル)

ボーカリスト・歌手が、作曲者・アレンジャーに渡すための音域情報をシンプルにまとめる完全無料のWebアプリケーション。
このアプリに興味を持ってくれてありがとうございます！がんばってつくりました。
音楽制作活動をする中で、ボーカリスト・アレンジャー間のやり取りとして必要だと思った経験を元にしました。

👉 **[Webアプリを開く (Live Demo)](https://ebs13quei.github.io/VocalScope/)**

---

## 主な機能

1. **作曲者専用の視覚化レイアウト**
   - **ピアノ鍵盤 (C2〜C6)** と同期した3層スタックバー。
   - **「⭐ 得意域 (Good Zone)」** と **「可能域 (Total Range)」** の濃淡2重レイヤー表示で、サビのキー選定やメロディ設計を強力にアシスト。
   - 地声 (Chest / Modal)、張った声 (Belt / Mix)、裏声 (Falsetto / Head) に対応。

2. **2つの測定モード**
   - 🎙️ **オート測定**: マイクに向かって歌うと、ピッチをリアルタイム検出して自動プロット。発声練習用ガイド音（5音スケール）付き。
   - ✏️ **マニュアル設定**: 鍵盤タップで音を確認しながら、セレクトボックスや微調整ボタン（◀ ▶）で手動メモ。

3. **ワンタップで「作曲者用カード画像」を保存**
   - 自身の写真（アバター）を取り込み可能。
   - スマホの共有メニュー（写真アプリへの保存、LINE送信等）から、16:9の高解像度プロファイルカード画像を直接共有できます。

4. **スマホ完全対応 (PWA)**
   - スマホの「ホーム画面に追加」を行うことで、アプリ感覚でフルスクリーン利用可能。

このアプリを利用してもサーバー上にデータは保存されないので、安心してお使いいただけます。
